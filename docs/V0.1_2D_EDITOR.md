# Kineo v0.1 — Interactive 2D Editor

## Implemented

- The existing dark Kineo interface is now connected to the canonical Zustand document:
  the sidebar lists bodies and joints, the canvas renders the mechanism, and the
  inspector edits the selected entity.
- A slider-crank example opens by default with a fixed base, crank, connecting rod,
  piston, four liaison instances, local anchors and planar geometry.
- Users can add rigid bodies, select and rename/recolor them, edit their local-frame
  position and planar orientation, and drag them in the viewport. The ground is drawn
  as a fixed rail and cannot be moved or deleted.
- The joint library adds pivot, slider, cylindrical, spherical, planar, helical and
  fixed liaison instances. The inspector edits the joint name, connected bodies, world
  position and DOF values. Canvas dragging updates the joint's local attachment
  coordinates for both connected body frames.
- The viewport draws segment and rectangle geometry, class colors, labels, axes and
  schematic joint symbols. Selection is available from the scene and entity list.
- Canvas controls provide grid visibility, 10-unit snapping, zoom (wheel and buttons),
  fit-to-scene, and Shift-drag panning. Pointer dragging moves bodies and joints;
  document positions and their connected attachments update in the store.
- Header controls open and save JSON v3.0. Document edits support undo/redo via
  buttons, Ctrl/Cmd+Z, Ctrl/Cmd+Y, and Ctrl/Cmd+Shift+Z.

The joint library uses symbols that distinguish each liaison type in the planar
viewport. They are schematic representations appropriate for an editor preview;
formal ISO/AFNOR certification of the drawn glyphs has not been performed.

## Tested

See [`TEST_RESULTS.md`](./TEST_RESULTS.md) for the automated and browser checks.
The browser smoke test created a body and joint, exercised undo/redo and JSON export
controls, and dragged the crank from the canvas; the inspector reflected the snapped
position change.

## Remaining / out of scope

- No kinematic solver, motion simulation, mobility or hyperstatism calculation; the
  solver control is deliberately disabled and the interface does not show fabricated
  results.
- 3D, graph and split views are explicit placeholders.
- No geometry drawing palette, SVG/PNG export, autosave, or direct inspector controls
  for individual local anchor coordinates. Moving a joint on the canvas updates those
  local coordinates.
- Imported Z coordinates and quaternion orientation are retained in JSON but the
  canvas displays only the XY plane and class planar rotation.
